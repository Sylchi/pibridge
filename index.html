💾 Flash SD Card via USB

1 Insert SD card into USB card reader and connect to PC
2 Click "📀 Flash SD Card" — select the reader in the USB picker
3 Browser writes PiBridge boot image directly to raw blocks (like dd)
4 Put SD card in Pi, power on — connects via BLE

Uses WebUSB + SCSI WRITE10 to write a bootable image. Chrome/Edge on Linux. On Windows, install WinUSB via Zadig for the reader first.

Insert SD card reader, then click Flash.
⬇ .img.gz
⚠️ All data on the SD card will be overwritten. The image contains a FAT32 boot partition with PiBridge firmware. ~33 MB image, writes in a few seconds.
