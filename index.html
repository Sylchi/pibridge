📡 Connect to Pi

First time? Get your Pi Zero W ready:

  1. Flash Raspberry Pi OS Lite to SD card
  2. Download the Pi firmware below
  3. Copy pibridge.py to the SD card's /opt/ folder
  4. Add empty ssh file to boot partition (enables SSH)
  5. Add dtoverlay=dwc2 to config.txt
  6. Insert SD card in Pi, power it up, wait 30s
  7. Click Connect above — Pi shows up as "PiBridge"
